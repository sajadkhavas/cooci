# بازطراحی صفحه اصلی وینیمی — ۱۴۰۵/۰۶/۰۲

## دامنه تغییر

- بازنویسی هیرو با پیام روشن، متن خوانا و حذف المان‌های شناور مزاحم
- جایگزینی نوار تزئینی با نوار قابل پیمایش با لمس، ماوس و صفحه‌کلید
- بازطراحی کارت دسته‌بندی با جداسازی تصویر از متن و پشتیبانی از یک یا چند دسته فعال
- اضافه‌شدن تصویر اختصاصی بهینه‌شده برای دسته کوکی‌های خانگی
- نمایش تمام‌قاب تصویر محصول و چیدمان ویژه برای حالت تک‌محصول
- بازطراحی مسیرهای مناسبتی، مراحل سفارش، راهنماها و فراخوان پایانی
- اصلاح کنتراست رنگ و جایگزینی سبز تیره تعاملی با خانواده تراکوتا/هلویی
- بازنویسی نوار اعتماد و نمایش امن تصویر رسمی اینماد بدون اجرای HTML دریافتی
- بازطراحی کامل فوتر، گروه‌بندی لینک‌ها، آکاردئون موبایل و ثبت نام SHINETHREE بدون پیوند

## قراردادهای حفظ‌شده

- داده محصول، دسته، قیمت و موجودی همچنان از API و SSR loader موجود دریافت می‌شود.
- هیچ داده نمایشی یا ادعای تأییدنشده‌ای به مسیر تولید اضافه نشده است.
- مسیرهای قدیمی و ساختار URL فروشگاه تغییر نکرده‌اند.
- رفتار سبد خرید، احراز هویت، پرداخت و بک‌اند در این تغییر دست‌کاری نشده است.
- اطلاعات تماس رسمی: 09212508746، hello@winimibakery.com و اندیشه، استان تهران.

## معیار پذیرش

- بررسی TypeScript، ESLint و تمام تست‌های واحد
- ممیزی دسترس‌پذیری، محتوای عمومی، طراحی مدرن و هویت برند
- بیلد production با API واقعی و mocks غیرفعال
- بررسی بودجه JavaScript، CSS، تصاویر، SSR و PWA
- کنترل تمیزی diff و ثبت SHA قبل از استقرار

## استقرار

تغییرات فقط پس از ثبت در GitHub و ساخت release تغییرناپذیر روی سرور فعال می‌شوند. فعال‌سازی باید اتمیک، همراه با health check و امکان rollback فوری باشد.
